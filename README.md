# HastKala — Indian Artisan & NGO Marketplace

> Connecting authentic Indian artisans & grassroots NGOs with conscious buyers, volunteers, and donors.

## Live Deployment Ready
This repository contains the production-ready build of HastKala.

### Features
- **Warm Heritage Design System**: Earthy craft aesthetics, accessible WCAG AA contrast palette.
- **Pure Web Stack**: HTML5, CSS3 (Vanilla design tokens), Bootstrap 5.3 CDN, GSAP 3 & ScrollTrigger.
- **Zero Heavy Backend Dependencies**: Instant, client-side dynamic search and filtering.
- **Responsive & Mobile-First**: Touch targets >= 44px, offcanvas bottom-sheet filters.

### Deploy on Vercel
Import this repository directly into Vercel with zero build configuration.
